# 🚀 COSMIC FURY

**An action-packed space survival game featuring intense combat, powerful bosses, upgrades, and endless challenges.**

## 🎮 About the Project

COSMIC FURY is a browser-based space action game where players battle enemies, survive increasingly difficult waves, unlock powerful abilities, and take on challenging bosses.

## ✨ Features

- 🚀 Space combat and enemy encounters
- 👾 Boss battles
- ⚡ Player upgrades and abilities
- 🔥 Combo-based gameplay
- 🎵 Game audio and sound effects
- 🎯 Increasing difficulty and challenges

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Zustand
- CSS

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/chetan02103-lang/cosmic_fury.git
   ```

2. Enter the project directory:

   ```bash
   cd cosmic_fury/cosmic-fury
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🏗️ Build

```bash
npm run build
```
